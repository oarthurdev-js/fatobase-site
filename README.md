# fatobase-site

Landing page do Fato Base. HTML/CSS/JS puros, sem build — publicada pelo GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).

- Contato: defina o número em `main.js` (`WHATSAPP`, só dígitos com 55 + DDD).
- Preview local: `python3 -m http.server` e abra http://localhost:8000.
