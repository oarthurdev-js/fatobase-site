# canal-dark-site

Landing page do Canal Dark Sem Esforço. HTML/CSS/JS puros, sem build, publicada pelo GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).

- Contato: defina o link em `main.js` (`CONTATO`: t.me, formulário ou mailto:).
- Preview local: `python3 -m http.server` e abra http://localhost:8000.
